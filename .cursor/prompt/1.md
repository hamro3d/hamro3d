Conduct a full audit and improvement pass on these two pages:
1. http://localhost:3000/products
2. http://localhost:3000/products/:id (use any valid product ID)

## Step 1 — Skill & Rule Gap Check
Before anything else, review the existing skills in `.cursor/skills/` and rules in `.cursor/rules/`. If any of the following specialist perspectives are missing as a skill or rule, create them first:
- UI/UX reviewer (interaction design, visual hierarchy, Hamro3D design token compliance)
- QA engineer (broken states, edge cases, empty states, accessibility)
- Frontend engineer (performance, component structure, Nuxt 3 best practices)

## Step 2 — Deep Audit (use Playwright MCP + file reads)
For each page, evaluate from all four perspectives simultaneously. For every finding, note: what it is, why it matters, and how severe it is (Critical / Major / Minor).

**Frontend Engineer lens:**
- Component reuse, prop hygiene, unnecessary re-renders
- Nuxt 3 / Vue 3 Composition API correctness
- Tailwind CSS v4 token usage vs. raw values
- SSR safety, hydration issues

**QA lens:**
- All interactive controls (filters, tabs, gallery, CTAs) — do they work correctly?
- Edge cases: empty filter results, single image, no GIF, no social videos, long product names
- Responsive layout at 375px, 768px, 1280px, 1440px (use Playwright viewport resize)
- Accessibility: keyboard nav, focus-visible states, ARIA labels, colour contrast

**UI/UX lens:**
- Visual hierarchy: does the eye land on the right things in the right order?
- Section and tab sequential order — does it match the brand's emotional journey?
- Spacing, typography scale, and motion — do they feel premium and intentional?
- Call-to-action clarity and placement
- Information density — too much? Too little?

**Brand & Product Owner lens:**
- Every piece of copy, label, and CTA — does it pass the Hamro3D language guidelines? (commission not order, piece not product, etc.)
- Does the page feel like a memory — or just a product listing?
- Is anything that detracts from the emotional story present?
- Missing sections or content that would increase trust or desire?

## Step 3 — Prioritised Fix List
After the audit, produce a prioritised list of issues grouped as:
- 🔴 Critical (broken functionality or brand violation)
- 🟡 Major (noticeable UX friction or significant brand misalignment)
- 🟢 Minor (polish, consistency, copy)

## Step 4 — Implement
Fix all Critical and Major issues. For Minor issues, fix any that are quick wins (under ~15 lines of change). Leave the rest noted but unimplemented.

## Step 5 — Verify
Use Playwright to visually verify each fix at desktop (1440px) and mobile (375px). Take screenshots for any visual changes.

Apply every decision through the Hamro3D strategic filter:
> "Does this feel like a memory — or just a product?"
