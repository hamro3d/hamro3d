## Task: Build the /memories page

### Step 0 — Install dependency
Run: `npm install html2canvas`

### Step 1 — Mock data
Create `app/data/mock-memories.ts` with the `MockMemory` interface (see skill) and 10 seeded entries. Each entry must:
- Have a unique `slug`, realistic `customerFirstName`, `occasion`, and `location` (all Nepal-based)
- Have a `storyBody` written in the Hamro3D brand voice — warm, editorial, intimate — exactly as a studio artisan would describe the piece they made
- Have `images` pointing to `/images/memories/{slug}/1.png` (use existing product images as placeholders — e.g. `/images/products/custom-human-figurine/1.png`)
- Have a `shareCaption` under 280 characters that feels personal, not promotional
- Have `shareHashtags: ['#Hamro3D', '#MemoryToObject', '#MadeInNepal', '#HandcraftedInKathmandu']`
- At least 3 entries should have a `tiktokVideoId` or `instagramPostId` (use placeholder IDs like `"abc123"`)

### Step 2 — Composable
Create `app/composables/useMemoryShare.ts` exactly as specified in the skill, including:
- `html2canvas` capture at 2× scale with `backgroundColor: '#10081a'`
- Web Share API with file support (mobile)
- Desktop fallback: download PNG + copy caption to clipboard
- A `useShareToast` reactive ref that shows a brief confirmation message

### Step 3 — H3dMemoryCard component
Create `app/components/H3dMemoryCard.vue` following the card anatomy in the skill:
- Hero image with bottom gradient overlay (`from-h3d-base/80 to-transparent`)
- Eyebrow, story headline (1 line clamp), story body (2 line clamp), customer credit line, tag pills
- Action row with two buttons:
  - **"Share this story"** — icon (share/upload SVG) + label. On click, calls `shareMemory(memory, cardEl)` from the composable. Show `useShareToast` confirmation below the button.
  - **"Leave a memory ↓"** — smooth-scrolls to the comment section of that card
- A `ref="cardEl"` on the shareable card wrapper (the area `html2canvas` will capture — exclude comment section from capture)
- The card wrapper must be a `<article>` with `aria-label` set to the story headline

### Step 4 — Comment section (inside H3dMemoryCard)
Below the card action row, add a collapsible comment section (collapsed by default, opens on "Leave a memory ↓" click):
- Shows stored `LocalComment[]` from `localStorage` key `h3d_comments_${memory.slug}`, sorted newest first
- Each comment shows: commenter name (bold, `font-h3d-display text-sm`), comment text (`font-h3d-body text-xs text-h3d-muted`), relative time (e.g. "2 days ago")
- Input form: Name field + message textarea + submit button ("Leave your memory")
- On submit: push to localStorage, clear form, re-render list
- Empty state: *"Be the first to leave a memory."*
- Section label heading: *"Memories shared"* (`font-h3d-display text-base`)

### Step 5 — Social embeds
For memories with `tiktokVideoId` or `instagramPostId`, render the embed below the comment section. Load embed scripts only on `onMounted` via `useHead` to avoid SSR errors. Wrap in a `<div class="mt-6">` with a label *"See it in action"*.

### Step 6 — /memories index page
Create `app/pages/memories/index.vue`:
- `useSeoMeta` with `title: 'Memories'`
- Page hero section (same visual pattern as `/our-story` header):
  - Eyebrow: "PIECES WE HAVE MADE · हाम्रा स्मृतिहरू"
  - H1: *"Moments we have held."*
  - Subtext: *"Every piece here began with a story. These are the ones people trusted us to keep."*
  - Radial gradient atmosphere overlays (same as other page headers)
- Product count line: *"X memories and counting."* (derived from data length)
- `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-5` of `<H3dMemoryCard>` components
- Empty state branded message if array is empty

### Step 7 — Navbar
Add "Memories" link to `app/components/layout/H3dNavbar.vue` in both the desktop link list and the mobile menu, between "Our Story" and "Connect".

### Step 8 — Verify with Playwright
Navigate to `http://localhost:3000/memories` at 1440px and 375px. Take screenshots. Confirm:
- All 10 cards render with images, story text, and action row
- "Share this story" button is visible and has correct ref
- Comment section opens on click and accepts input
- Social embed section appears on cards that have `tiktokVideoId`
- No layout shifts, no console errors

Apply every decision through the Hamro3D strategic filter:
> "Does this feel like a memory — or just a product?"
